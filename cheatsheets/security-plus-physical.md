# Security+ Physical Security

## Perimeter
Fence · gate · bollard · barrier · lighting.

## Entry / access
Locks · badges · biometrics · guards · turnstiles · mantrap.

Mantrap = controlled two-door entry area.

## Detection
CCTV · alarms · access logs · motion/intrusion sensors.

Badge log anomalies and after-hours access are useful investigation evidence.

## Environmental
HVAC/cooling · fire suppression · water detection · UPS · generators · redundant power/cooling.

## Physical attacks
Tailgating = follow authorized person.  
Piggybacking = authorized person lets another in.  
RFID cloning = copy weak badge credentials.  
Device theft = direct access to hardware/data.

## Removable media
USB can bypass network perimeter controls and enable malware/data theft.

Controls: USB device control, application control, endpoint monitoring, encryption, secure disposal.

## Deception
Honeypot = decoy system.  
Honeynet = decoy network.  
Honeytoken = decoy secret/identifier.  
Honeyfile = decoy data/file.

## Control mindset
**Prevent access → detect access → delay attacker → limit impact → preserve evidence.**
