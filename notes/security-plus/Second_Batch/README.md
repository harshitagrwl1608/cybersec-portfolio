# Security+ SY0-701 — Professor Messer Lecture Notes (New Batch)

This folder is a **standalone digital reconstruction of one new 96-page batch of handwritten Security+ notes**. The notes are the student’s own lecture notes taken from Professor Messer’s free CompTIA Security+ **SY0-701** video course. **The older Security+ notebook batch is not included here.**

Professor Messer’s official course index is the basis for the course-title and section alignment used in this repository:
https://www.professormesser.com/security-plus/sy0-701/sy0-701-video/sy0-701-comptia-security-plus-course/

## What is in this batch

- **96/96** source pages preserved as individual reference images.
- **31 standalone topic Markdown files.**
- **17 Mermaid diagram/flowchart blocks** embedded directly in the relevant topic files.
- Each topic file is designed to be understandable without opening a source image or another note.
- `source-images/` is reference-only and is never required reading.

## Reading model

Open any file under `topics/` as a **standalone study note**. It contains the definitions, explanations, examples, notebook-specific details, practical security guidance where applicable, and reconstructed diagrams needed to understand the topic. The source images are kept separately only for checking the handwriting against the digital reconstruction.

## Fidelity policy

The handwritten notebook is the primary source for the exact examples, ordering, terminology, and classroom emphasis. External technical verification is used to check standards, current guidance, and technical terminology; it does not silently replace the notebook content. Where handwriting is genuinely unreadable, `[unclear]` is used instead of inventing text.
