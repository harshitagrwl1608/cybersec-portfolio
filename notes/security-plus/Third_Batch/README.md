# Security+ SY0-701 Notes — Batch 03

A standalone, topic-wise Markdown reconstruction of the **84-page October 11, 2026 scan** supplied for this batch. This package contains **only Batch 03**; earlier Security+ batches are not included.

The notebook material is organized around the Professor Messer CompTIA Security+ SY0-701 course sequence. Each topic file is intended to teach its topic independently, without requiring the reader to open a scan, visit another note, or consult an external page to understand the main concepts.

## Start here

1. Open [`INDEX.md`](INDEX.md) for all 30 topics and their coverage.
2. Open [`PAGE_COVERAGE.md`](PAGE_COVERAGE.md) to audit coverage of all 84 pages.
3. Browse [`topics/`](topics/) for standalone lessons.
4. Use [`source-images/INDEX.md`](source-images/INDEX.md) only when you want to inspect the page-level source scan.

## Standalone-note principles

- Definitions, explanations, relevant examples, security controls, and practical context are included within each topic.
- Mermaid diagrams are embedded in the relevant topic Markdown files so GitHub can render them inline.
- Topic files do not link to the source-image folder and do not depend on it to explain a topic.
- Source scans are stored separately for reference only, with one index file for each of the 84 pages.

## Research and verification

Technical explanations were cross-checked against the Professor Messer SY0-701 course pages and applicable primary references such as NIST, CISA, OWASP, SigmaHQ, IETF RFCs, FIRST CVSS, the U.S. Department of Justice, and official privacy/regulatory resources.
