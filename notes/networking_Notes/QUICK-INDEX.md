## Study order

A practical progression is: OSI → devices → IP/ARP/DHCP → common protocols → subnetting/IPv6 → routing/NAT/VLANs/STP → wireless → DNS/time → management → VPN/AAA/PKI → security architecture → segmentation/IoT → attacks → device security.
