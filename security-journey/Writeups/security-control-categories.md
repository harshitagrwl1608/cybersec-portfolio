# Security Control Categories — Home Setup Examples

**Path:** CompTIA Security+ (SY0-701) / General Security Concepts
**Date:** 2026-09-07
**Category:** Security Controls

## Objective
Give one concrete example from a home setup for each of the four security control categories: technical, managerial, operational, and physical.

## Tools used
- Home router/firewall
- Laptop/phone security settings
- Physical home access controls

## Methodology (Just example)

1. **Technical control:** Home router firewall rules and device security controls are implemented by technology to restrict or protect access.
2. **Managerial control:** A household security policy can define who is allowed to access the Wi-Fi/network, how passwords are handled, and when credentials are changed.
3. **Operational control:** Regularly reviewing connected devices, updating systems, and following a repeatable backup/checking procedure are actions performed by people.
4. **Physical control:** A locked room/door or physically securing the router and devices limits physical access to the assets.

The examples are mapped to the four control categories without changing the category definitions from the notes.


## Detection angle (SOC-relevant)
A SIEM would mainly see evidence from the technical/operational controls: firewall events, authentication events, device-management logs, and configuration changes. Physical and managerial controls are usually evidenced through policy records, access logs, and audit records rather than a SIEM event alone.

## Key takeaway
The same security objective can be supported by different control categories; the category describes how the control is implemented or enforced.
