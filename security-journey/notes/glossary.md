# Glossary

Own-words definitions. Add a term whenever you hit a gap. Target: 20+ terms.

## Fundamentals
| Term | Definition |
| --- | --- |
| Red Team | Offensive side: simulates attackers to find weaknesses. |
| Blue Team | Defensive side: detects, responds to and prevents attacks. |
| IOC (Indicator of Compromise) | Evidence that a system may be compromised (odd hash, IP, login pattern). |
| TTP | Tactics, Techniques and Procedures: how an attacker operates. |
| Kill Chain | Stages of an attack from reconnaissance to actions on objective. |
| CIA Triad | Confidentiality, Integrity, Availability. |
| AAA | Authentication, Authorization, Accounting. |

## Malware types
| Term | Definition |
| --- | --- |
| Virus | Malicious code that attaches to a file and needs user action to spread. |
| Worm | Self-replicating malware that spreads across networks without user action. |
| Trojan | Malware disguised as legitimate software. |
| Ransomware | Encrypts data and demands payment for the key. |
| Rootkit | Hides malicious activity by operating deep in the OS or firmware. |

## Phishing types
| Term | Definition |
| --- | --- |
| Spear phishing | Targeted phishing aimed at a specific person or group. |
| Whaling | Phishing aimed at senior executives. |
| Vishing | Phishing by voice call. |
| Smishing | Phishing by SMS. |

## Social engineering
| Term | Definition |
| --- | --- |
| Pretexting | Inventing a believable scenario to extract information. |
| Baiting | Luring a victim with something tempting (e.g. infected USB drive). |
| Tailgating | Following an authorized person into a restricted area. |
| Quid pro quo | Offering a benefit in exchange for information or access. |

## Cryptography
| Term | Definition |
| --- | --- |
| Symmetric encryption | One shared key encrypts and decrypts. |
| Asymmetric encryption | Public/private key pair. |
| Hashing | One-way function that proves integrity, not secrecy. |

## SOC / Defensive
| Term | Definition |
| --- | --- |
| SIEM | Collects and correlates logs to raise alerts. |
| SOC Tier 1 / 2 / 3 | Triage / deep investigation / threat hunting and engineering. |
| Chain of custody | Documented handling of evidence to keep it admissible. |
