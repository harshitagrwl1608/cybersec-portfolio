# Physical Security
1. **Barricades / Ballards**

   - Identify safety concerns
   - E.g. concrete barriers, bollards etc.
2. **Access control vestibules**
   - Locked / unlocked doors based on condition
   - If one opens -> all other locked
   - Allow / control access
