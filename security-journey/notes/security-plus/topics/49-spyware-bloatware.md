# Spyware & Bloatware
## Spyware
- Malware that spies on you
  - and identity theft, affiliate fraud
- Can trick into installation
  - peer-to-peer, fake security software
- Browser monitoring
  - Activity watch
  - keylogger etc.

### Page 97
## PROTECTION
- Maintain AVs (anti-malware)
- Always know what you're installing
- HAVE BACKUP
  - as this can be easy to remove
  - virus scan Malwarebytes

## Bloatware
- On a comp./mobile
  - no. of unnecessary apps
- Manufacturers paid by Apps
  - No choice
- Use valuable storage space
  - and resource usage
  - may make things slower
  - could open system to exploits

### Page 98
# Removing bloatware
- Identify & remove
  - might be diff
  - use in-built installer
- Some apps have their own uninstallers
  - third-party cleaners & uninstallers
  - not a first option
  - have backups
