# Physical Security

## Overview
Physical security protects people, facilities, devices, and supporting infrastructure from unauthorized access, theft, tampering, environmental damage, and service disruption.

## Core concepts
- Perimeter controls include fences, gates, bollards, barriers, and lighting.
- Entry controls include locks, badges, biometrics, guards, mantraps, and turnstiles.
- Detection includes cameras, alarms, access logs, and intrusion sensors.
- Environmental controls include HVAC, fire suppression, water detection, power protection, and redundant cooling.

## Practical examples
- A server room may use badge access, a mantrap, cameras, temperature monitoring, UPS systems, and fire suppression together.

## Security / mitigation
- Apply least privilege to physical access, review access logs, test alarms, and protect backup media and networking equipment from tampering.

## Detection / troubleshooting
- Unexpected badge use, after-hours entry, repeated denied access, camera alerts, and environmental alarms can provide investigative evidence.
