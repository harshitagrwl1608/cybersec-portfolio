# Spyware & Bloatware

## Overview
Spyware monitors or collects information without appropriate consent; bloatware is unnecessary software that consumes resources and may create extra attack surface. The two categories are not identical.

## Core concepts
- Spyware may include keylogging, browser monitoring, credential theft, or activity collection.
- Bloatware may be harmless but can increase resource consumption, privacy exposure, maintenance burden, or attack surface.
- Untrusted installers and fake security tools are common spyware delivery paths.

## Practical examples
- A browser extension that silently captures browsing activity is closer to spyware; a vendor-preinstalled unused application is usually bloatware.

## Security / mitigation
- Install software only from trusted sources, review permissions, remove unnecessary applications, keep anti-malware tools current, and maintain backups.

## Detection / troubleshooting
- Unexpected browser extensions, startup entries, outbound telemetry, resource spikes, and unfamiliar processes may indicate unwanted software.
