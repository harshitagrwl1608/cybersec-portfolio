# A02 — Security Misconfigurations
 
## Definition
Occurs when systems are deployed with unsafe defaults, incomplete settings,
or exposed services. Even a small misconfiguration can expose sensitive
data, enable privilege escalation, etc.
 
## Common Patterns
1. Default or weak credentials
2. Unnecessary services/endpoints exposed to the internet
3. Misconfigured cloud storage or permissions
4. Unrestricted API access / missing authentication or authorization
5. Verbose error messages exposing stack traces
6. Outdated software
7. Exposed AI/ML endpoints without proper access controls
